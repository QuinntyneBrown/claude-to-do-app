## Per-slice loop trace

1. **Tests first** (commit `190f302`). Tests reference `User.PendingEmail*`, `/api/account/email-change/{request,confirm}`, and `DELETE /api/account/email-change` — none of which existed pre-slice.
2. **Implementation:**
   - **Domain:** `User` extended with `PendingEmail`, `PendingEmailTokenHash`, `PendingEmailExpiresAt` (all nullable). Plaintext token never persisted.
   - **Migration #006 `AddPendingEmailFields`** — three nullable columns on `Users`.
   - **Infrastructure:** `AppDbContext` configures `PendingEmail` (≤256) and `PendingEmailTokenHash` (≤128) max-lengths.
   - **Application:**
     - `Account.EmailChange.RequestEmailChangeCommand` (+ validator + handler). Validator: `NotEmpty` + `EmailAddress` + ≤256. Handler normalises new email, rejects 400 if equal-to-current or already-taken, generates 32-byte plaintext token, stores sha256-hex hash with 2-hour expiry, calls `IEmailService.SendEmailChangeVerificationAsync(newEmail, plaintext)`. Returns updated `MyProfile`.
     - `Account.EmailChange.ConfirmEmailChangeCommand` (+ validator + handler). Validates: pending-email present, token hash matches, expiry not in the past. On success: swaps `Email`, clears all pending fields. On any failure: 400 generic via `ValidationFailureException`.
     - `Account.EmailChange.CancelEmailChangeCommand` (+ handler). Clears all pending fields unconditionally.
     - `GetMyProfileQueryHandler` and `UpdateDisplayNameCommandHandler` updated to surface `user.PendingEmail` instead of the B-006 placeholder `null`.
   - **Api:** `AccountController` adds `POST /email-change/request`, `POST /email-change/confirm`, `DELETE /email-change` (all `[Authorize(Roles="User")]` via the controller-level attribute). New transport DTOs `EmailChangeRequest` and `EmailChangeConfirmRequest`.
   - **Tests:** rely on the existing `TestEmailService` (B-004 swap) — its `LastEmailChangeToken` / `LastEmailChangeAddress` capture the request handler's output.
3. **Build + test:** `dotnet build -warnaserror` 0/0; `dotnet test` 23/23 green (4 new + 19 pre-existing).
