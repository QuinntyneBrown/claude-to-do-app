## Per-slice loop trace

1. **Tests first** (commit `87c9616`). Tests reference `IEmailService`, `PasswordResetTokens`, the two new endpoints, and a `TestEmailService` seam that captures the plaintext token issued by the request handler. Build was red until this slice landed.
2. **Implementation:**
   - **Domain:** `PasswordResetToken` entity (`Id`, `UserId`, `TokenHash`, `ExpiresAt`, `ConsumedAt?`).
   - **Application:**
     - `IEmailService` interface (`SendPasswordResetAsync`, `SendEmailChangeVerificationAsync` — second method is unused in B-004, kept for B-007 reuse per BP plan).
     - `IAppDbContext` exposes `PasswordResetTokens`.
     - `Auth.PasswordReset.RequestPasswordResetCommand` (+ validator + handler) — looks up user, no-ops on miss (no enumeration), generates 32-byte random plaintext, stores sha256 hex hash, writes `PasswordResetRequested` audit, calls `IEmailService` with plaintext.
     - `Auth.PasswordReset.CompletePasswordResetCommand` (+ validator + handler) — finds reset token by hash, rejects if consumed/expired (`ValidationFailureException` → 400), updates `User.PasswordHash`, marks token consumed, revokes ALL active `RefreshToken`s for the user, writes `PasswordResetUsed` audit, issues fresh access + refresh tokens, returns `AuthenticationOutcome`.
     - `Common.ValidationFailureException` — small helper that wraps a `(propertyName, message)` pair as a FluentValidation `ValidationException` so it surfaces through the existing `ExceptionToProblemDetailsMiddleware` as HTTP 400 `application/problem+json`.
   - **Infrastructure:**
     - `Email.LoggingEmailService : IEmailService` — the deferred no-op. Logs the *intent* (`[no-op email] would send password-reset to {Email}`) without the plaintext token (token can be retrieved from the database in dev / test when needed).
     - `AppDbContext` configures the `PasswordResetTokens` table with a unique-`TokenHash` index, a non-unique `UserId` index, cascade-by-user.
     - `DependencyInjection` registers `IEmailService` → `LoggingEmailService` (singleton).
   - **Migration #005 `AddPasswordResetTokens`.**
   - **Api:** `AuthController` adds `POST /api/auth/password-reset/request` (`[AllowAnonymous]`, returns 202) and `POST /api/auth/password-reset/complete` (`[AllowAnonymous]`, writes refresh cookie, returns `SignInUserResult`). HTTP request DTOs (`PasswordResetRequest`, `CompletePasswordResetRequest`) live alongside the controller, no annotations.
   - **Tests:** `TickboxApiFactory` swaps `IEmailService` → `TestEmailService`, which records the last password-reset email + plaintext for inspection. `Reset()` available for fresh state when needed.
3. **Build + test:** `dotnet build -warnaserror` 0/0; `dotnet test` 12/12 green.
