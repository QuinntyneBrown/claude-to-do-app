## Per-slice loop trace

1. **Tests first** (commit `19b1f37`). New `e2e/page-objects/todo-detail.page.ts` POM with locators for title / notes / due-date / status chips / save / delete / confirm dialog / error / activity items. `e2e/specs/todo-detail.spec.ts` (5 cases).
2. **Implementation:**
   - **api:** new `TodoDetail`, `TodoActivity`, `TodoActivityKind`, `UpdateTodoRequest` types in `todo-detail.ts`. `ITodosService` extended with `getById`, `update`, `delete`; `toggleStatus` return type changed from `Todo` to `TodoDetail` (keeps the API symmetric — every Todo write returns the full detail). Concrete `TodosService` adds GET `/api/todos/{id}`, PUT `/api/todos/{id}`, DELETE `/api/todos/{id}` (B-011 / B-012 / B-014).
   - **components:** new `ConfirmDialogComponent` (`tb-confirm-dialog`) + `ConfirmDialogData` interface — Material 3 dialog with confirm + cancel actions, `destructive` flag toggles the confirm button to `warn` color. `data-testid` on the dialog root + each action so any future destructive flow (delete account in F-009) reuses this without re-introducing locators.
   - **domain:**
     - `TodoActivityListComponent` (`tb-todo-activity-list`) — read-only list rendering `Created` / `Marked complete` entries with localised "DD MMM, HH:mm" timestamps (REQ-TODO-8 AC2). `data-testid="todo-activity-item"` on each entry.
     - `TodoEditFormComponent` (`tb-todo-edit-form`) — title (`max 200`), notes (`max 2000`), due-date (native `type="date"`), status chip-set (only rendered in edit mode). On save: PUT (edit) or POST (create); on delete: emits `deleted` event (the page handles the dialog); on status chip click: PATCH and emits `statusChanged` so the page can refresh the activity strip.
   - **tickbox:** `TodoDetailPageComponent` (`tb-todo-detail-page`) — wraps `AppShellComponent`, reads `:id` from `ActivatedRoute.paramMap`. If `id === 'new'` or absent → create mode (form only). If `id` is a guid → edit mode: fetches `TodoDetail`, renders the form + activity strip. On `deleted` from the form, opens `ConfirmDialogComponent` with destructive variant; on confirm, calls `delete` and routes back to `/todos`. On `saved`, routes back to `/todos`. On `statusChanged`, updates the local `todo` signal so the activity strip re-renders.
   - **routes:** `/todos/new` and `/todos/:id` added as lazy `loadComponent`s.
   - **F-005 fix-up:** `TodosListComponent.onToggle` now projects the `TodoDetail` response down to `Todo` shape before patching the local list (B-013's response is now `TodoDetail` per the unified contract). One-line projection; same observable behaviour.
3. **Build + test:** `ng build api/components/domain/tickbox` all 0 warnings 0 errors. Playwright spec set: 23/23 green (5 new + 18 from prior slices).
