2. **Implementation:**
   - **Application:**
     - `Todos.ToggleTodoStatus.ToggleTodoStatusCommand(Id, Status: TodoStatus)`.
     - `ToggleTodoStatusCommandValidator`: `RuleFor(x => x.Status).IsInEnum()`.
     - `ToggleTodoStatusCommandHandler`:
       - Composite-filter lookup `(t.Id == id && t.UserId == _currentUser.UserId)` → 404 path for cross-user / not-found.
       - If `Status == Complete` and current is `Incomplete`: set `CompletedAt = now`, insert `TodoActivityEntry { MarkedComplete }`.
       - If `Status == Incomplete` and current is `Complete`: clear `CompletedAt`, remove the latest `MarkedComplete` activity row.
       - If status unchanged: no-op (idempotent).
       - Returns `TodoDetail` (same shape as B-011 / B-012).
   - **Api:** `TodosController.ToggleStatus` (`PATCH /api/todos/{id:guid}/status`). Transport DTO `ToggleTodoStatusRequest(Status: string)` — the controller parses the string into the `TodoStatus` enum (case-sensitive `Enum.TryParse` + `Enum.IsDefined`) and throws `ValidationFailureException` on miss, surfacing as 400. This deliberately keeps the rest of the API's enums on the wire as int (System.Text.Json default) — the alternative was a global `JsonStringEnumConverter`, which would have churned every existing response shape's clients without buying anything else.
