## Per-slice loop trace

1. **Tests first** (commit `2b0684b`). New `e2e/page-objects/profile.page.ts` POM with locators for `profile-email`, `profile-display-name`, `display-name-input`, `display-name-save`, `display-name-error`, `current-password-input`, `new-password-input`, `change-password-submit`, `change-password-error`, `sign-out-button`. `e2e/specs/profile.spec.ts` (6 cases).
2. **Implementation:**
   - **api:** new `MyProfile`, `UpdateDisplayNameRequest`, `ChangePasswordRequest` types in `my-profile.ts`. New `IAccountService` contract + `ACCOUNT_SERVICE` injection token (`account.service.contract.ts`) with `getMyProfile`, `updateDisplayName`, `changePassword`. Concrete `AccountService` hits GET `/api/account/me`, PUT `/api/account/display-name`, PUT `/api/account/password` (B-006 / B-008). `IAuthService` extended with `signOut(): Observable<void>`; concrete impl POSTs `/api/auth/sign-out` with `withCredentials: true` so the HttpOnly refresh cookie is revoked server-side (B-003).
   - **domain:**
     - `ProfileSummaryComponent` (`tb-profile-summary`) — `<dl>` rendering email + display name with `data-testid` on each value.
     - `DisplayNameEditComponent` (`tb-display-name-edit`) — `mat-form-field` + Save button. Trims whitespace; client-side blank check sets the inline error before any network call. On success emits `(updated)` with the returned `MyProfile` so the page can refresh the summary.
     - `ChangePasswordFormComponent` (`tb-change-password-form`) — current + new password fields (`type="password"`, `autocomplete=current-password` / `new-password`), submit button. On 4xx the inline error band shows ("Could not change password. Check your current password and try again.").
     - All three reuse `ErrorBannerComponent` (from F-002) for the inline error region — consistent error surface across forms.
   - **tickbox:** `ProfilePageComponent` (`tb-profile-page`) — wraps `AppShellComponent`, fetches profile in `ngOnInit` and stores it in a `signal<MyProfile | null>`. Composes `ProfileSummaryComponent` + `DisplayNameEditComponent` + `ChangePasswordFormComponent` + a "Sign out" `mat-stroked-button`. On display-name update the page replaces the profile signal so the summary re-renders. Sign-out calls `IAuthService.signOut`, then unconditionally clears `AuthStateService` and routes to `/sign-in` (the local clear is intentional even on network error so the user is never trapped in a half-signed-out state).
   - **routes:** `/profile` added as a lazy `loadComponent`, guarded by `authGuard`.
   - **wiring:** `app.config.ts` provides `ACCOUNT_SERVICE` → `AccountService`.
3. **Build + test:** `ng build api/components/domain/tickbox` all 0 warnings 0 errors. Playwright spec set: 29/29 green (6 new + 23 from prior slices).
