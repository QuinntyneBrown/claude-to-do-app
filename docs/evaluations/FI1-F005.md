2. **Implementation:**
   - **api:** `Todo` extended with `notes` and `dueDate` fields (already present on the backend). `ITodosService.toggleStatus(id, request)` added to the contract; `ToggleTodoStatusRequest { status: TodoStatus }` model. Concrete `TodosService.toggleStatus` PATCHes `/api/todos/{id}/status` (B-013).
   - **components:**
     - `EmptyStateComponent` (`tb-empty-state`) — slotted CTA, `--error` modifier (used by F-010), `data-testid` input.
     - `LoadingBarComponent` (`tb-loading-bar`) — wraps `mat-progress-bar` for consistent token-driven shape.
     - `AppShellComponent` (`tb-app-shell`) + `AppShellNavItem` interface — layout grid with `topbar`/`main`/`navbar` on mobile, switching to a 2-column grid with `rail` at ≥600px and an expanded labelled rail at ≥1240px. Bottom nav-bar shown on mobile only. Both nav surfaces use `routerLinkActive` to highlight the current section. `data-testid` on the shell, the rail, and the bar so the F-011 responsive-sweep spec (and this slice's specs) can target them by breakpoint.
   - **domain:**
     - `TodoListItemComponent` (`tb-todo-list-item`) — checkbox + title + due-date label ("Due today"/"Due tomorrow"/`d MMM`). `data-testid` is `incomplete-item` or `complete-item` depending on status; the inner checkbox carries `data-testid="todo-checkbox"`.
     - `TodoFilterChipsComponent` (`tb-todo-filter-chips`) — `mat-chip-set` with All / Incomplete / Complete; emits `filterChanged` with the new filter.
     - `TodosListComponent` rewritten: today's-date page header, "n of m complete" count summary, filter chips, two `<section>`s for Incomplete + Complete, empty state when there are no todos. Uses signals + computed for derived state. Toggling a checkbox calls `ITodosService.toggleStatus` and patches the local list with the server response.
   - **tickbox:** `TodosPageComponent` rewritten to wrap an `AppShellComponent` (with To-dos / Profile nav items) around the list, plus an extended `mat-fab` "New to-do" linking to `/todos/new` (the route lands in F-006).
3. **Build + test:** `ng build api/components/domain/tickbox` all 0 warnings 0 errors. Playwright spec set: 18/18 green (5 new + 13 from prior slices).
