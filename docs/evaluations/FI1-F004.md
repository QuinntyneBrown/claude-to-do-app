## Note on Begin_oidc test pattern

The test `Begin_oidc_redirects_to_authorization_url` uses Playwright's `page.route('https://idp.test/**', ...)` to intercept the IdP URL the app would otherwise navigate to, fulfilling with a placeholder HTML page so the test stays at the same browser context but the URL changes. `expect.poll(() => page.url(), ...)` then asserts the redirect occurred. This avoids the brittleness of trying to monkey-patch `window.location.assign`, which is non-configurable in modern browsers.

## Note on `dist/` paths and ng serve

Mid-slice, an `ng serve` race condition surfaced where the dev server cached stale path resolutions for the `'api'`/`'components'`/`'domain'` aliases (pointing at `./dist/<name>`) when those library bundles were rebuilt while the server was already running. Fix: stop ng serve, do a full sequential rebuild of every library + the app, **then** start ng serve. The slice is otherwise complete; this is documented for future FI1 slices so we don't re-discover it.
